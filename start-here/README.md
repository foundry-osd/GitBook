# Start here

Use this section to understand Foundry, verify the administrator workstation, and complete a first deployment.

## Before you begin

You need:

- A supported Windows administrator workstation.
- Local administrator permissions.
- Internet access for application dependencies, Windows media, and driver catalogs.
- An ISO output location or a USB drive that can be erased.
- A supported target device for the first deployment.

Review the complete [requirements](requirements.md) before creating deployment media.

## Recommended path

1. Review the [deployment workflow](deployment-workflow.md).
2. Complete the [quick start](quick-start.md).
3. Configure advanced networking, customization, or Windows Autopilot only when the deployment requires them.
4. Test the media on non-production hardware before using it at scale.
