# Configure deployment media

Foundry OSD is the Windows desktop application used to prepare deployment media.

## Recommended order

1. Validate [Windows ADK and Windows PE](adk.md).
2. Review [general configuration](general.md).
3. Configure [network access](network/README.md) when required.
4. Choose a [Windows Autopilot](autopilot/README.md) method when required.
5. Select [Windows customization](customization/README.md) options.
6. [Create deployment media](media/README.md).

The **Start** page aggregates readiness information from these areas. Resolve blocking items before starting media creation.
