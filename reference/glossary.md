# Glossary

## ADK

Windows Assessment and Deployment Kit. Foundry OSD uses its deployment tools to prepare Windows PE media.

## Driver pack

A vendor or model-specific package containing drivers used during Windows deployment.

## Foundry Connect

The Windows PE application that establishes and validates network readiness before deployment.

## Foundry Deploy

The Windows PE application that selects deployment inputs and applies Windows to the target device.

## Foundry OSD

The administrator workstation application that configures and creates deployment media.

## Hardware hash

Device identity data used to register a device with Windows Autopilot.

## OOBE

Windows out-of-box experience shown when a deployed installation starts for initial setup.

## Target disk

The physical disk selected for Windows installation. Foundry erases and repartitions this disk during deployment.

## Windows Autopilot

Microsoft cloud provisioning technology used to prepare a device for organizational setup.

## Windows PE

Windows Preinstallation Environment. Foundry Connect and Foundry Deploy run in this environment.
