# App removal

Use App removal to remove selected provisioned Windows applications during deployment.

## Configure removal

1. Open **Customization > App removal**.
2. Enable app removal.
3. Select only applications approved for removal.
4. Review dependencies and organizational application requirements.
5. Return to **Start**.

{% hint style="warning" %}

{% endhint %}
