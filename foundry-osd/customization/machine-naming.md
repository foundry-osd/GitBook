# Machine naming

Use Machine naming to define how a computer name is selected during deployment.

## Naming requirements

Foundry Deploy validates names as 1–15 characters containing letters, numbers, or hyphens.

{% hint style="warning" %}
Choose a naming method that prevents duplicate names and matches directory, inventory, and device-management requirements.
{% endhint %}

## Configure naming

1. Open **Customization > Machine naming**.
2. Enable the required naming behavior.
3. Configure the available values or pattern exposed by Foundry OSD.
4. Return to **Start** and confirm customization readiness.
